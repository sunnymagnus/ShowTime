# Local fonts

The interface bundles these Google Fonts files so that its appearance does not require an external font request.

- DM Sans variable font: https://github.com/google/fonts/tree/main/ofl/dmsans
- Manrope variable font: https://github.com/google/fonts/tree/main/ofl/manrope

Both are distributed under the SIL Open Font License. Their original license notices are included as `OFL-DMSans.txt` and `OFL-Manrope.txt`.
